# Better Compiler

> [!WARNING]  
> 🚧 This project is still in early development. Expect frequent changes and incomplete features.

## About

**Better Compiler** is an open-source toolkit for safe and flexible code execution.  
It allows you to **compile and run JavaScript, TypeScript, and Python** code in a sandboxed environment,  
either on the **client (browser)** or on the **server**.

Key features:
- 🔒 **Sandboxing** – isolate untrusted code securely.
- 🌍 **Client & Server** – run code in the browser or backend.
- ⚡ **Multi-language** – support for JavaScript, TypeScript, and Python.
- 🧩 **Extensible** – designed to integrate with any platform or workflow.
